Algebra Notes

Understand Algebra with simple explanations and examples.

1. Introduction to Algebra

Algebra is a branch of mathematics that uses letters and symbols to represent unknown numbers.

Example:

x + 5 = 10

x = 10 - 5

x = 5

2. Important Algebraic Terms

Variable: A letter representing an unknown number.

Constant: A fixed numerical value.

Coefficient: A number multiplied by a variable.

Expression: A combination of numbers, variables and operations.

3. Important Algebra Formulas

1. (a + b)² = a² + 2ab + b²

2. (a - b)² = a² - 2ab + b²

3. a² - b² = (a + b)(a - b)

4. (a + b)³ = a³ + 3a²b + 3ab² + b³

5. (a - b)³ = a³ - 3a²b + 3ab² - b³
